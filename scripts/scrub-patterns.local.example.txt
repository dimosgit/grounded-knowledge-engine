# matched case-insensitively against tracked files.

#   - private client, employer, or project names

#   - private repository, workspace, or vault slugs
#   - figures, endpoints, or distinctive phrases copied from private material
#
# Deliberately published maintainer metadata — the demo domain, the public
# repository name — does not belong here: blocking it only trains you to bypass
# the gate.
