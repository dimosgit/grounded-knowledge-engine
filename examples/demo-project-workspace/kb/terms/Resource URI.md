# Resource URI

## Definition

The address that names one piece of readable context, such as a file or a project
summary. The router demo exposes project context at a gke:// address.

## Retrieval anchors

- Exact term: resource URI.
- Application-controlled context.
- gke://project/router-rollout/context is a resource URI.
