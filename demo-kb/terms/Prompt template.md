# Prompt template

## Definition

A reusable message pattern that a server offers and the person picks on purpose,
often as a slash command. Arguments fill the template before it reaches the model.

## Retrieval anchors

- Exact term: prompt template.
- User-controlled, unlike tools.
- Templates take named arguments.
