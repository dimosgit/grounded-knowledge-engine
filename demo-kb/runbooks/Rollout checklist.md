# Rollout checklist

Steps before showing the router to anyone.

1. Build the index from scratch and confirm every answer cites a file and line.
2. Resume [[projects/router-rollout/project|Router Rollout]] in a fresh session.
3. Ask one question the notes cannot answer and confirm the agent says so.
4. Capture one new learning and confirm it lands in the note that owns it.
5. Keep the [[Rollback plan]] open during the session.
