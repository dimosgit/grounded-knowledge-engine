# Sanitized design kit

This directory contains public-safe inputs for the Operator Cockpit area-first
flow and dual themes.

## Files

- [`../../design.md`](../../design.md): canonical design and architecture brief.
- [`sample-focus-data.json`](./sample-focus-data.json): neutral area and focus
  fixture.
- [`sample-planning-data.json`](./sample-planning-data.json): fictional planning
  and retrospective fixture.
- [`stitch-prompt.md`](./stitch-prompt.md): reusable visual-design prompt.
- [`implementation-status.md`](./implementation-status.md): implemented behavior
  and verification status.

Raw design-service exports, generated screenshots, workspace-specific labels,
and portable archives are intentionally excluded from the public repository.
The application uses local assets and sanitized fixtures rather than remote
design-service dependencies.
